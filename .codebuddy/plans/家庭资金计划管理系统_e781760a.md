## 产品概述

家庭资金计划管理系统,帮助家庭成员管理财务规划、预算控制和资金分配。

## 核心功能

- 成员管理: 添加家庭成员,管理成员信息和权限
- 资金管理: 收入管理(工资、奖金、投资收益)、支出管理(日常消费、账单、储蓄)
- 预算规划: 周/月/年资金计划,预算设置和跟踪
- 资金审批: 成员申请资金,其他成员审批流程
- 资金分配: 不同类别的资金分配比例设置
- 数据统计: 图表展示收支情况、预算执行率
- 提醒功能: 系统内提醒(账单提醒、预算预警、审批通知)
- 报表导出: 导出财务统计报表

## 技术栈

- 后端: Java 17 + Spring Boot 3.x + MyBatis Plus + Spring Security + JWT
- 前端: Vue 3 + TypeScript + Vite + Element Plus + Pinia + ECharts
- 数据库: MySQL 8.0
- 构建工具: Maven (后端) + npm (前端)

## 技术架构

### 系统架构

- 架构模式: 前后端分离架构,RESTful API设计
- 后端分层: Controller层 → Service层 → Mapper层 → Database
- 前端分层: 视图层 → 组件层 → 状态管理(Pinia) → API调用层
- 认证授权: JWT Token + Spring Security,基于角色的权限控制

### 模块划分

- 用户认证模块: 登录、注册、权限验证
- 成员管理模块: 家庭成员CRUD、角色权限
- 资金管理模块: 收入/支出记录、分类管理
- 预算规划模块: 周/月/年预算设置、预算跟踪
- 审批流程模块: 资金申请、审批流程
- 统计报表模块: 数据可视化、报表导出
- 提醒通知模块: 系统内消息提醒

## 目录结构

- backend/src/main/java/com/familyplan/controller - REST API控制器
- backend/src/main/java/com/familyplan/service - 业务逻辑层
- backend/src/main/java/com/familyplan/mapper - 数据访问层
- backend/src/main/java/com/familyplan/entity - 实体类
- frontend/src/views - 页面组件
- frontend/src/components - 公共组件
- frontend/src/stores - Pinia状态管理
- frontend/src/api - API接口
- database/init.sql - 数据库初始化脚本

## 数据库设计

- 用户表: user_info (id, username, password, nickname, avatar, role, status, create_time)
- 成员表: family_member (id, user_id, member_name, relation, role, status)
- 收入表: income_record (id, member_id, amount, category, source, date, remark)
- 支出表: expense_record (id, member_id, amount, category, type, date, remark)
- 预算表: budget_plan (id, member_id, period_type, amount, month, year, week)
- 审批表: approval_record (id, applicant_id, amount, purpose, status, approver_id, create_time, approve_time)
- 资金分配表: fund_allocation (id, member_id, category, percentage, period)
- 提醒表: notification (id, user_id, title, content, type, is_read, create_time)

## 设计风格

采用现代化简洁风格,使用Vue3 + Element Plus构建响应式界面,注重用户体验和数据可视化。

## 页面规划

- 登录页: 简洁的登录表单
- 仪表盘: 收支概览、预算进度、待办事项
- 成员管理页: 成员列表、添加成员
- 收支管理页: 收支记录列表、添加记录
- 预算规划页: 预算设置、预算跟踪
- 审批管理页: 审批列表、审批操作
- 统计报表页: 图表展示、报表导出
- 提醒中心: 消息提醒列表
