# 家庭成长系统 · 微信小程序端

基于原生微信小程序（WXML/WXSS/JS）构建，与后端 Spring Boot 服务共用一套接口。

## 目录结构

```
wechat-miniprogram/
├── app.js                  # 全局入口，登录态管理
├── app.json                # 页面注册、tabBar、窗口配置
├── app.wxss                # 全局样式
├── config.js               # 后端服务地址配置
├── sitemap.json
├── utils/
│   ├── request.js          # 请求封装（JWT、成员头、401 处理）
│   ├── api.js              # 后端接口集合
│   └── util.js             # 工具函数（金额/日期/分类）
└── pages/
    ├── index/              # 首页（本月概览、快捷记账、功能入口、最近收支）
    ├── record/             # 记账（收入/支出，分类、日期、来源、备注）
    ├── workbench/          # 每日工作台（按日任务、优先级、完成度）
    ├── statistics/         # 统计（分类占比环形图、月度柱状图）
    ├── profile/            # 我的（成员切换、修改密码、退出登录）
    ├── login/              # 登录 / 注册
    ├── members/            # 家庭成员管理
    ├── budget/             # 预算规划（月度/年度/自定义）
    ├── approval/           # 资金审批（申请、通过、拒绝）
    ├── notifications/      # 通知中心（未读数、已读/删除）
    ├── fixedExpense/       # 资金管理（固定支出）
    ├── lifePlan/           # 美好生活计划（家电/旅游）
    └── growthPlan/         # 儿童成长计划（短期/长期目标、进度）
```

## 使用说明

1. **配置后端地址**：修改 `config.js` 中的 `baseUrl`，默认 `http://localhost:8080`。
2. **导入项目**：打开微信开发者工具 → 导入项目 → 选择本目录，AppID 使用测试号（`touristappid`）即可。
3. **关闭域名校验**：开发者工具「详情」→「本地设置」→ 勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。
4. **运行后端**：确保后端服务已启动，直接编译即可。

## 功能清单

- 家庭账号注册/登录（一个家庭一个账号）
- 家庭成员管理，支持切换「当前记账成员」
- 收入/支出记账（分类、日期、金额、备注）
- 预算规划与剩余额度
- 大额支出资金审批流程
- 每日任务工作台（今日/周期/一次性）
- 固定支出项目管理与月度概览
- 美好生活计划、儿童成长目标（进度跟踪）
- 收支分类统计与月度趋势图表
- 通知中心

## 注意事项

- 后端返回统一结构 `Result{code, message, data}`，`request.js` 已自动解包，页面直接使用 `data`。
- 所有业务请求需携带 JWT（`Authorization: Bearer <token>`）及当前成员 `X-Member-Id` 请求头。
- 若需真机调试，需将 `baseUrl` 改为局域网可访问地址，并在小程序后台配置合法域名。
